# Evidencia de ejecución

La carpeta está preparada para artefactos de corridas reales. Usa identificadores coherentes con la bitácora y guarda, cuando corresponda, el prompt o transcripción, el diff o hash del cambio, la salida de pytest, el JUnit y el veredicto. Ejemplos de nombres de futuros archivos: `multi-r0-pytest.log`, `multi-r0-junit.xml` y `multi-r0-revision.md`.

Anota la revisión o el estado exacto que produjo cada artefacto. Si el código tenía cambios sin commit, conserva el diff y los archivos nuevos pertinentes o registra el hash de una instantánea reproducible. Mantén los datos identificables y credenciales fuera de los artefactos compartidos.
